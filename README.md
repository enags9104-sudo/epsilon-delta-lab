# ε-δ 实验室

面向**高等数学初学者**的交互式可视化应用，用拖拽与动画讲清极限的 ε-δ 严格定义。

> 极限不是"越来越接近"，而是一场关于任意小的博弈。

## 最快上手

克隆仓库后先构建一次单文件版：

```bash
npm install
npm run build:single
```

然后双击打开生成的 **`epsilon-delta-lab.单文件版.html`** 即可，无需安装任何东西、无需联网。
单个 HTML 文件已内联全部 JS、CSS 与字体。

## 项目包含什么

| 路径 | 说明 |
| --- | --- |
| `epsilon-delta-lab.单文件版.html` | 单文件成品（构建生成，未入库），双击即用 |
| `dist/` | 标准多文件构建产物（构建生成，需通过本地服务器打开） |
| `src/` | 完整源码 |
| `src/lib/math.ts` | 数学核心引擎：函数模型、极限判定、临界 δ 二分搜索 |
| `src/lib/plot.ts` | 绘图与坐标换算 |
| `scripts/bundle-single-file.mjs` | 把 `dist` 打包成单文件的脚本 |

## 开发与构建

```bash
npm install         # 安装依赖
npm run dev         # 本地开发服务器
npm run build       # 构建到 dist/
npm run build:single  # 构建 + 生成单文件版
npm run preview     # 预览构建产物
```

## 四个功能区

1. **交互实验室** —— 拖动画面上的红色把手调 ε、蓝色把手调 δ，实时看到 ε 带（水平）
   与 δ 带（竖直）的交叠区是否"包住"曲线。含 6 个函数，其中 3 个极限不存在（取整、
   跳跃、高频振荡），用于演示"找不到 δ"的情形。点「自动搜索合格 δ」可动画演示数值
   二分搜索出的临界 δ*。

2. **定义拆解** —— 把定义原文拆成 6 步，以"对手 / 我方 / 裁判"三方博弈的视角逐步讲解，
   并附完整定义原文的正确排版。

3. **ε → δ 对应表** —— 展示同一函数在不同 ε 下所需的临界 δ*，直观呈现"δ 依赖 ε"
   这一核心事实。

4. **找茬挑战** —— 给定 ε，从 4 个候选 δ 中选出合格的（或判断"都不行"），含计分与连击。

## 技术要点

- **React 19 + TypeScript + Vite**，零运行时 UI 库依赖，动画全部用 CSS 实现。
- **数学引擎**（`src/lib/math.ts`）自行实现：曲线采样、`|f(x)−L|` 上确界近似、
  临界 δ 的二分搜索。振荡型反例采用向 a 加密的三次分布采样，确保不会漏掉极值。
- **绘图**（`src/lib/plot.ts`）采用 x/y 等比缩放，保证 ε/δ 的"方形邻域"直觉成立。
- **完全离线**：字体自托管（Playfair Display / Inter Tight / IBM Plex Mono 的可变字体
  子集），构建产物无任何外部请求。

## 已知限制

- 临界 δ* 由数值搜索得出，与解析解可能存在微小误差；本站目的是建立直觉，严格证明仍需
  按定义书写。
- 多文件 `dist/` 版受浏览器 ES module 的 CORS 限制，不能直接双击打开；请用
  `npm run preview`，或直接使用单文件版。
